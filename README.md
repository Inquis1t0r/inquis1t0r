### 🏗️ Architecture & Cloud

Designing event-driven, cloud-native systems with security as a first-class architectural constraint — not a retrofit.

- **Distributed Systems:** Event-Driven Architecture, CQRS, Event Sourcing, eventual consistency trade-offs.
- **Cloud Architecture:** Multi-account AWS / Azure landing zones, IAM at scale, infrastructure as code (Terraform, CDK).
- **API & Integration:** REST, GraphQL, gRPC, Kafka — synchronous vs. asynchronous boundary decisions.
- **Domain-Driven Design:** Bounded contexts, Event Storming, anti-corruption layers.
- **Observability by Default:** OpenTelemetry, distributed tracing, SLO-driven architecture.

---

### 🔐 Core Security Architecture

Security decisions made at the architecture level — before the first line of code.

- **Zero Trust Architecture:** Identity-driven segmentation, assume-breach design, continuous verification.
- **Identity & Access:** OAuth2, OIDC, SAML, RBAC/ABAC, secrets management.
- **Threat Modeling at Scale:** STRIDE, Attack Trees, MITRE ATT&CK as an architectural language.
- **Applied Cryptography:** PKI, TLS 1.3, mTLS, key lifecycle, HSM integration.
- **Secure SDLC:** SLSA framework, SAST/DAST/SCA in CI/CD, supply chain integrity.

---

### ☠️ Deep Security Specialization — Malware Analysis & Reverse Engineering

*Hobby-grade depth. Architecture-grade application.*

I reverse-engineer real malware to understand how systems actually fail — not how textbooks say they fail. This directly informs my architectural decisions: defense-in-depth, isolation boundaries, and attack surface reduction are grounded in real adversary behavior, not abstract threat models.

- **Binary Reverse Engineering:** Static & dynamic analysis of PE/ELF binaries, shellcode extraction, deobfuscation, unpacking using **IDA Pro**, **Ghidra**, and **x64dbg**.
- **OS Internals:** Windows kernel structures, Native API (Nt/Zw), Linux syscall interface, process injection techniques.
- **Threat Intelligence:** Dissecting C2 protocols, extracting IOCs, mapping TTPs to architectural mitigations.
- **Tooling & Automation:** Custom disassembler scripts, analysis pipelines, and emulators in **Python**, **C/C++**, and **Go**.
